## Dump stability verdict

**No machine-readable bytecode dump exists.**

- `bil vm --dump-bytecode` prints `BytecodeProgram`'s `Display` impl (`src/vm.rs`), which formats each op with Rust **`{:?}` (Debug)**.
- There is **no** `--format json` (or other stable encoder) for bytecode. JSON exists only for `bil verify` / `bil model-check` obligation reports.
- `bil dump-ir --level lir` still prints **signatures only** (`exec_fn emit_ok() -> Int`); not a lowering input.
- bil itself golden-snapshots the Debug text (`tests/ir_snapshots.rs` → `tests/snapshots/bytecode_*.txt`), so the shape is *locally* frozen by bil CI, but **Debug is not a public format guarantee**.

**Recommendation for B3.2:** treat the current dump as a **disciplined Debug-text contract** (grammar below). Prefer **checked-in `.bc.txt` fixtures** for bil1asm tests; optionally accept a live `bil vm --dump-bytecode` subprocess when a pinned bil is present. Do **not** depend on bil as a Cargo crate. Upstream `--format json` remains desirable but is out of scope until bil adds it.

## How the dump is produced

```text
bil vm <file.bil> [--seed N] [--dump-bytecode]
```

Pipeline (`driver.rs`): parse/check → multi-level IR → `BytecodeProgram::compile` → execute VM → if `--dump-bytecode`, `print!("{}", bc)` **then** print `name = value` results.

Implications for a subprocess consumer:

1. Dump is mixed with runtime output lines (`ident = …`). Parse only the image block (header + `.fn` / `.global` sections); ignore trailing result lines.
2. The program must **run successfully** to get a dump (compile/exec errors abort before print).
3. Seed affects nondeterministic GCL branch choice at runtime, **not** the dumped instruction list.
4. `assertions` are counted in the header's instruction total but **never printed** (and top-level `assert` is largely erased before LIR anyway).

### Outer layout (live sample)

```text
=== BIL Bytecode VM Image (N functions, G globals, I instructions, E ghost items erased) ===
  .fn name(param, …):
    0000: PushInt(79)
    0001: StoreVar("a")
    …
    0009: Return
  .global g1:
    0000: PushInt(48)
    …
```

- Header: informational; ignore counts for parsing.
- Functions: `BTreeMap` iteration order → **sorted by function name**.
- Globals: declaration order from LIR.
- Each instruction line: four-digit zero-padded index, `: `, then Debug of `BytecodeOp`.
- Nested ops (guards, actions) appear **inline on one line** as nested Debug (no extra `NNNN:` for nested code).

## Inventory: `BytecodeOp` Debug shapes

Defined in `/home/bill/src/lang/bil/src/vm.rs`. Derived `Debug` (no custom formatter). Nested enums from `ast.rs` / `ir/lir.rs` also use derived Debug.

|---------|-------------------------|-------|

| `PushBool(bool)` | `PushBool(true)` | Reject (unless later bool→0/1 profile) |
| `PushStr(String)` | `PushStr("hi")` | Rust string Debug (escapes) |
| `LoadVar(String)` | `LoadVar("x")` | Placeholder `_` compiled as `LoadVar("_")` |
| `StoreVar(String)` | `StoreVar("a")` | |
| `PopVar(String)` | `PopVar("a")` | let-binding teardown |
| `Unary(UnaryOp)` | `Unary(Neg)` / `Unary(Not)` | `UnaryOp`: `Not`, `Neg` |
| `Binary(BinOp)` | `Binary(Add)` | Unit-style enum Debug — **not** Display (`+`) |
| `MakeList(usize)` | `MakeList(2)` | Reject |
| `MakeStruct { concept, fields }` | `MakeStruct { concept: "Point", fields: ["x", "y"] }` | Reject |
| `UpdateStruct { fields }` | `UpdateStruct { fields: ["x"] }` | Reject |
| `GetField(String)` | `GetField("x")` | Reject |
| `Call { func, argc }` | `Call { func: "double", argc: 1 }` | Only intrinsics lower |
| `PipeStage { stage, arg }` | `PipeStage { stage: "map", arg: Some(Binary(Add, Placeholder, Int(1))) }` | `arg` is `Option<LirExpr>` Debug — reject |
| `GuardedSelect { branches }` | see below | Profile subset |
| `GuardedLoop { inits, branches, then_code }` | see below | Profile subset |
| `Match { arms }` | `Match { arms: [(Variant("Normal", []), [PushInt(0)]), …] }` | Reject |
| `Quantifier { kind, var, domain_code, body_code }` | `Quantifier { kind: Forall, var: "x", domain_code: […], body_code: […] }` | Reject |
| `Return` | `Return` | Entry → `Halt` |

### `BinOp` Debug names (all appear as `Binary(<Name>)`)

`Implies`, `Iff`, `And`, `Or`, `Eq`, `Neq`, `Lt`, `Le`, `Gt`, `Ge`, `In`, `Add`, `Sub`, `Mul`, `Div`, `Mod`, `Range`, `RangeInc`, `Pipe`.

### `CompiledAction` (inside select/loop)

| Variant | Debug shape |
|---------|-------------|
| `ReturnExpr(Vec<BytecodeOp>)` | `ReturnExpr([PushInt(1)])` |
| `AssignState(Vec<(String, Vec<BytecodeOp>)>)` | `AssignState([("x", [LoadVar("x"), PushInt(1), Binary(Sub)])])` |
| `Nop` | `Nop` |
| `TrapAbort` | `TrapAbort` — **always reject** (no SoftISA abort; must not emit `E0..=EF`) |

### Nested control examples (verbatim)

**GuardedSelect** (`if … fi`):

```text
GuardedSelect { branches: [([LoadVar("x"), PushInt(0), Binary(Eq)], ReturnExpr([PushInt(1)])), ([LoadVar("x"), PushInt(0), Binary(Gt)], ReturnExpr([LoadVar("x"), PushInt(1), Binary(Sub)]))] }
```

**GuardedLoop** (`do … od then …`):

```text
GuardedLoop { inits: [("x", [LoadVar("n")])], branches: [([LoadVar("x"), PushInt(0), Binary(Gt)], AssignState([("x", [LoadVar("x"), PushInt(1), Binary(Sub)])]))], then_code: [LoadVar("x")] }
```

**Match** / **Pattern** Debug: `Wildcard`, `Var("p")`, `Int(…)`, `Bool(…)`, `Str(…)`, `Variant("ReliefRequired", ["p"])`.

**QuantifierKind**: `Forall`, `Exists`, `Choose`.

**PipeStage `arg`**: full `LirExpr` Debug (`Int`, `Var`, `Placeholder`, `Binary(Add, …)`, …) — different grammar from top-level `BytecodeOp::Binary(BinOp)`.

## Profile vs reject (aligned with b3-lowering.md)

### Accept / lower (BIL1 profile)

| Dump form | SoftISA / notes |
|-----------|-----------------|
| `PushInt(k)` + `StoreVar` | `LoadImm k` · `Store @slot` if `0 ≤ k ≤ 255` |
| `LoadVar` | `Load @slot` |
| `PopVar` | no code (slot lifetime ends) |
| `Binary(Add\|Sub)` with **literal** RHS already on stack as `PushInt` | `AddImm` / `SubImm` |
| `Binary(Eq)` / compare-to-literal used as select/loop guard | `SubImm` · `Jz` / `Jz` patterns per b3-lowering |
| `Binary(Gt)` as `x > 0` (non-neg proven) | `Load` · `Jz` |
| `GuardedSelect` with deterministic, disjoint, profile-shaped guards | `Jz` / `Jmp` chain |
| `GuardedLoop` with single decrement branch + `variant` (erased but required upstream) | counted loop template |
| `AssignState` of profile exprs | compute → `Store` |
| `Call { func: "bil1_out", argc: 1 }` | `Out` |
| `Call { func: "bil1_weaken", argc: 1 }` | `Weaken` (imm ∈ {0,1,2}) |
| `Return` of **entry** fn | `Halt` |
| Ghost (`requires`/`ensures`/`invariant`/`variant`/…) | already erased; use only via separate `bil verify` (B3.3) |

### Reject (diagnostic; do not lower)

| Dump form | Reason |
|-----------|--------|
| `Binary(Mul\|Div\|Mod)` | no SoftISA mul/div |
| `Binary` with two non-literal operands (e.g. `LoadVar`/`LoadVar`/`Binary(Add)`) | no two-address ALU |
| `Binary(Lt\|Le\|Ge\|Neq\|…)` needing flags / non-profile guards | no flags |
| `Unary(Neg\|Not)` | no negate/not opcode (Neg also risks signed range) |
| `Call` to anything except `bil1_out` / `bil1_weaken` | no call stack; recursion never |
| `PushFloat`, `PushStr`, `PushBool` | not in SoftISA |
| `MakeList`, `MakeStruct`, `UpdateStruct`, `GetField` | heap/ADT |
| `Match`, `PipeStage`, `Quantifier` | ADT / pipeline / FOL runtime |
| Overlapping / nondeterministic `GuardedSelect` / `GuardedLoop` | SoftISA deterministic |
| `TrapAbort` / `CompiledAction::TrapAbort` | forbidden fake host-escape opcodes |
| `PushInt` outside `0..=255` without range proof | Int≠u8 |
| `.global` as entry / multi-fn programs beyond inlined helpers | entry is one fn; Call non-intrinsic rejected |
| `system` models | not a single program |

## Proposed stable textual IR for bil1asm (parse today)

**Name:** bil stack-bytecode text (`.bc.txt`).

**Sources:** (1) strip/normalize `bil vm --dump-bytecode` stdout into this form, or (2) hand-checked fixtures identical to that form.

### Grammar (informal)

```text
program     := header? section+
header      := '===' ... '===' NEWLINE          # ignored
section     := fn_section | global_section
fn_section  := '  .fn ' IDENT '(' params ')' ':' NEWLINE instr*
params      := ε | IDENT (', ' IDENT)*
global_section := '  .global ' IDENT ':' NEWLINE instr*
instr       := '    ' INDEX ': ' op NEWLINE
INDEX       := DIGIT{4}                         # decimal, zero-padded
op          := flat_op | nested_op

flat_op     := 'PushInt(' INT ')'
             | 'PushFloat(' FLOAT ')'
             | 'PushBool(' bool ')'
             | 'PushStr(' STRING_DEBUG ')'
             | 'LoadVar(' STRING_DEBUG ')'
             | 'StoreVar(' STRING_DEBUG ')'
             | 'PopVar(' STRING_DEBUG ')'
             | 'Unary(' unary ')'
             | 'Binary(' binop ')'
             | 'MakeList(' UINT ')'
             | 'MakeStruct { concept: ' STRING_DEBUG ', fields: [' string_list '] }'
             | 'UpdateStruct { fields: [' string_list '] }'
             | 'GetField(' STRING_DEBUG ')'
             | 'Call { func: ' STRING_DEBUG ', argc: ' UINT ' }'
             | 'Return'
             | 'TrapAbort' | 'Nop'              # actions may appear nested only

nested_op   := 'GuardedSelect { branches: [' branch_list '] }'
             | 'GuardedLoop { inits: [' init_list '], branches: [' branch_list '], then_code: [' op_list '] }'
             | 'Match { arms: [' arm_list '] }'
             | 'Quantifier { kind: ' qkind ', var: ' STRING_DEBUG ', domain_code: [' op_list '], body_code: [' op_list '] }'
             | 'PipeStage { stage: ' STRING_DEBUG ', arg: ' pipe_arg ' }'

branch      := '([' op_list '], ' action ')'
action      := 'ReturnExpr([' op_list '])'
             | 'AssignState([' assign_list '])'
             | 'Nop' | 'TrapAbort'
assign      := '(' STRING_DEBUG ', [' op_list '])'
init        := '(' STRING_DEBUG ', [' op_list '])'
op_list     := ε | op (', ' op)*
binop       := Ident as BinOp Debug name
unary       := 'Not' | 'Neg'
qkind       := 'Forall' | 'Exists' | 'Choose'
STRING_DEBUG:= Rust Debug string literal
INT         := Rust i64 Debug
```

**Parser rules (discipline):**

1. Accept only ASCII dump lines matching the shapes above; unknown variant names → hard error with line/op text.
2. Do not evaluate nested `LirExpr` inside `PipeStage` — reject the whole op.
3. Nested `op_list` uses the same `op` grammar (recursive).
4. After parse, run the **reject table** before lowering; profile checker is separate from the lexer.
5. Optional prelude line `.bil_bc_version 1` may be prepended to fixtures; live dumps lack it — default to v1.

This is intentionally a **parse of bil's Debug**, not a new pretty-printer, so fixtures can be captured with:

```bash
bil vm prog.bil --dump-bytecode | sed -n '/^===/,/^[^= ].*=/p' > prog.bc.txt
# then trim trailing `name = value` lines
```

## Recommended bil1asm module split (B3.2, not implemented)

Keep B3.1 assemble path intact. Add:

| Module | Responsibility |
|--------|----------------|
| `stack_bc.rs` | Lex/parse `.bc.txt` / dump text → `StackProgram { fns, globals }` AST mirroring `BytecodeOp` subset; no SoftISA knowledge beyond reject tagging helpers |
| `lower.rs` | Profile check (reject table) → slot assign → emit existing B3.1 profile IR text **or** direct `BytecodeImage` bytes; intrinsics `bil1_out` / `bil1_weaken`; entry `Return`→`Halt` |
| CLI (later) | `bil1asm lower --from-dump <file.bc.txt>` and/or `--from-bil <file.bil>` spawning pinned `bil vm --dump-bytecode` |

Flow: `dump/fixture → stack_bc::parse → lower::to_bil1 → encode` (reuse B3.1 header/budget rules from source metadata or CLI flags until B3.3 wires `bil verify`).

## Top risks

1. **Debug drift** — any bil enum/`#[derive(Debug)]` change breaks the parser; pin bil version + keep golden `.bc.txt`.
2. **Nested one-line Debug** — `GuardedSelect`/`GuardedLoop` lines are dense and recursive; brittle hand parsers; prefer a small recursive descent over regex.
3. **Version skew** — host binary still reports **v0.7.1** while sources are **0.8.1**; subprocess CI may dump a different dialect than fixtures.
4. **Dump requires successful execution** — non-runnable / nondeterministic-trap programs cannot be dumped; fixtures are mandatory for reject-path tests (`TrapAbort`, bad Call).
5. **u8 soundness** — dump carries bare `i64`; without B3.3 `bil verify` range proofs, lowering must reject wide ints rather than truncate.
6. **`PipeStage` embeds `LirExpr` Debug** — a different AST grammar inside the same file; easy to mis-parse if not rejected early.
7. **Assertions omitted from dump** — header instruction counts disagree with visible ops; do not trust the header for completeness.
